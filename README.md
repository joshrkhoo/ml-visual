# Gradient Lab

Interactive visualisations for COMP 4211 Machine Learning (Lectures 2–5), one topic per lecture idea:

- **L2** Fitting a line by gradient descent · Score, margin & hinge loss
- **L3** Overfitting & bias–variance · k-fold cross-validation
- **L4** Perceptron learning · AND/OR/XOR · Learning rate & SGD · Activation functions · Backprop on a graph · Momentum & local minima · Training an MLP · Universal approximation
- **L5** Convolution · Image filters · Padding & stride · Max pooling · Receptive field & parameter sharing

Single self-contained page: open `index.html`. Edit the files in `parts/` and run `./build.sh` to regenerate `index.html` and `lab.html` (the artifact source).
